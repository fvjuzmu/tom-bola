CSV-Format

Die CSV-Datei muss eine Kopfzeile mit den Spalten id und name haben. Eine optionale Spalte checked (true/false) wird beim Import berücksichtigt. Trennzeichen kann Komma oder Semikolon sein.

Suche

Die Suche findet Namen (Teilübereinstimmung) und IDs (ab dem ersten Zeichen).

Synchronisation

Häkchen werden sofort an den Server übertragen. Alle 10 Sekunden werden Änderungen anderer Geräte abgerufen. Der Sync-Status ist unten links in der Leiste sichtbar.

CSV importieren / exportieren

Der Import startet eine neue Tombola — die bisherige Datenbank wird automatisch gesichert. Der Export speichert die aktuelle Liste inklusive Abhak-Status als CSV-Datei.
